# Example structure

`9cht-ac.pdb` contains chains A (E6AP) and C (HPV16 E6) from PDB entry
[9CHT](https://www.rcsb.org/structure/9CHT). It was extracted from the existing
`~/binders200/pdb_data/pdb9cht.ent` reference on 2026-10-27.

The original atom records, coordinates, numbering, secondary structure records,
and residue identities are preserved. Chain B, its records, and unrelated header
records are omitted. This is an excerpt of the deposited complex, not the whole
biological assembly. B-factors are experimental model values, not pLDDT.

The example highlights E6AP regions 403–424 and 468–472 to demonstrate distinct
site styling. These are display selections, not a claim that these regions
account for every interaction. The contact report measures the selected A/C
partners using the configured heavy-atom cutoff.

Original structure publication: Kenny et al., Structure (2025),
[doi:10.1016/j.str.2024.12.013](https://doi.org/10.1016/j.str.2024.12.013).
